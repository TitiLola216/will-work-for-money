# Will Work For Money

## Verified Remote Job Search Instructions

Find the maximum number of legitimate, active remote jobs that can be performed from Cleveland, Ohio and were originally posted within the previous 24 hours. Search broadly and aggressively across employer career sites and legitimate ATS platforms first, then LinkedIn, Indeed, Built In, and other major job sites. Search multiple title and keyword variants across remote tech, customer success, customer service, inbound sales, technical account management, technical support, client success, SaaS, fintech, AI, automation, CRM, systems, operations, support, implementation, onboarding, and related roles. Use current-date/time evidence, not stale indexed snippets.

For every candidate, independently verify:

- Real employer
- Live employer/ATS application page
- Active role
- Fully remote or remote with Ohio/Cleveland explicitly eligible
- Original posting date/time within 24 hours, not merely a recent repost/update
- Requirements compatible with the user's background

## Hard filter

Never recommend a role whose stated experience requirements create an unfillable employment gap of more than 2 years based on the user's documented background.

## Sourcing and exclusions

Prefer employer-direct listings but accept job-board listings when independently verified. Reject duplicates, reposts, expired/filled roles, recruiter-only listings, scams, suspicious listings, roles requiring relocation outside Cleveland eligibility, and anything that cannot be fully verified. Do not default to zero. Continue searching and cross-checking until all major relevant source families and keyword/title clusters have been exhausted.

## Output

Rank verified matches by fit and return as many as qualify. For each provide:

- Title
- Company
- Location/work arrangement
- Salary, if available
- Exact verified posting age/date
- Match score
- Why the user fits
- Biggest gap
- Direct employer/ATS application link

Save every qualified result to the job tracker and notify the user when the verified report is ready. If zero truly remain after exhaustive verification, state exactly why each plausible lead was excluded and which source families were checked.
